Wave 1 - pre-commit hard-corruption gate
----------------------------------------

scripts/check_writes.py scans text files for the Windows <-> Linux
mount-sync damage signatures (embedded NUL bytes, silent
truncation, YAML parse failure) and exits non-zero on any
finding. scripts/hooks/pre-commit runs it against the staged
files and blocks the commit on a finding; activate per clone with
git config core.hooksPath scripts/hooks. This is the project's
first commit-blocking check - check_references.py stays warn-only
for soft findings (dangling references, schema warnings).

The gate caught a real pre-existing bug on its first run:
README.md had been committed truncated in commit 7c212f2 (the
last "Current state" table row and the closing sentence lost).
README.md is repaired here, and its badly stale counts refreshed
at the same time. CLAUDE.md's Verification section was rewritten
to describe the two checks and their different severity;
CHANGELOG.md gets a [0.8.1] entry (verification policy change, no
schema change).

Wave 2 - Ardbeg, the 14th distillery
------------------------------------

Adds Ardbeg as the fourteenth populated distillery - the fourth
and final south-Islay heavily-peated distillery, completing the
"Kildalton" peated cluster with Laphroaig, Lagavulin and Caol Ila.

- Port Ellen, south-coast Islay; founded commercially 1815
  (illicit distilling on the site reported from ~1794).
- One of the most turbulent closure/revival histories in the
  industry: mothballed 1981 under Hiram Walker, intermittent
  1989-1996, rescued by Glenmorangie plc in 1997, acquired with
  Glenmorangie plc by LVMH (Moet Hennessy) in December 2004.
- Distinctive feature: a purifier on the spirit-still lyne arm,
  uncommon on Islay; cross-referenced to glossary/reflux. A 2019
  still house doubled the still count from one pair to two.
- Bottlings: 10 Year Old (46% ABV, non-chill-filtered, natural
  colour, ex-bourbon core); Uigeadail (NAS bourbon + oloroso-
  sherry vatting, 54.2%); Corryvreckan (NAS bourbon + French-oak
  vatting, 57.1%).

Source conflicts are disclosed in ardbeg.NOTES.md: peating
recorded at both the ~50 ppm specification and the ~55 ppm
as-delivered average, not smoothed; annual capacity left null
because the 2019 expansion doubled capacity and no clean
producer-published post-expansion figure was found.

Critical eval caught and fixed an unsourced "1959 - Distillers
Company" ownership entry and a malt.source enum error
(external -> bought_in) before verify. One tracked forward
reference is introduced: ardbeg-corryvreckan cites
french-oak-cask, a cask entry not yet written.
